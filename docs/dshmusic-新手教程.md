# dshmusic 新手教程

> 在 Minecraft 里手持木棍就能听歌、搜歌、和朋友同步听同一首。
> 已安装于 **1.21.11 (NeoForge)** 和 **26.3 (Fabric)** 两个版本。

---

## 一、三步开始

### 第 1 步：拿一根木棍

木棍放在**主手或副手**都行。没有木棍就随便找块木板合成：

```
木板          木棍
██             ██
██   ──►       ██
██             ██
```

**创造模式**按 `E` 打开物品栏，搜索框输入 `stick` 直接拿。

### 第 2 步：看屏幕底部

木棍拿在手上时，屏幕下方会浮出一个小面板：

```
┌──────────────────────────────────┐
│ ♪ Boomin'Trilla — Max Verstappen ▶│
│ 0:56 ████████░░░░░░░░░░░░░░  3:16 │
└──────────────────────────────────┘
```

| 显示 | 含义 |
|---|---|
| 曲名 — 艺术家 | 正在播什么 |
| `▶` / `❚❚` / `■` | 播放中 / 暂停 / 停止 |
| `0:56` | 已播到第几秒 |
| 进度条 | 播放进度 |
| `3:16` | 总长 |

**没在放歌时**显示 `♪ 已索引 46 首`（= 音乐库里有几首歌）。
**一首都没有**显示 `扫描中…`（正在扫描磁盘，首次约 15~30 秒）。

### 第 3 步：右键木棍

弹出设置界面 —— 所有操作都在这里。

## 二、设置界面

```
♪ DSH Music    模式：本地播放    提供商：B站（音频区）
┌────────────────────────────┬──────────────────────────────┐
│ 搜索框                      │ [本地播放（点击切网络搜索）]    │
│                            │ [搜索] [提供商： B站（音频区）] │
│  《歌唱祖国》          3:8  │ [共享音乐： 关]               │
│  特别的人              4:19 │ [选择共享的玩家 (0)]          │
│  若生命等候            4:09 │ [⏮] [▶] [■] [⏭]             │
│  ...                       │ [音量 -] [音量 +] [重新扫描]   │
│                            │                              │
│  未在播放                   │           [关闭]              │
│  0/0 秒  音量 80%   未共享   │                              │
└────────────────────────────┴──────────────────────────────┘
```

### 左半边：歌单

- **滚轮**上下翻
- **点一下**某一首 = 立刻播放
- 正在播的那首显示为**绿色**
- 鼠标悬停的那行**高亮**

### 右半边：控件

| 按钮 | 作用 |
|---|---|
| **本地播放 / 网络搜索** | 点击切换模式。**本地**=播自己硬盘上的歌；**网络**=搜 B站 |
| **搜索** | 本地模式下把光标移到搜索框；网络模式下**真的去搜 B站** |
| **提供商** | 循环切换：本地库 / B站 / 网易云 / QQ音乐（后两个未实现） |
| **共享音乐** | 开关。开了才会把你在听什么发给别人 |
| **选择共享的玩家** | 选发给谁（独立子界面） |
| **⏮ ▶ ❚❚ ■ ⏭** | 上一首 / 播放暂停 / 停止 / 下一首 |
| **音量 - / 音量 +** | 独立于游戏音效音量 |
| **重新扫描** | 手动重扫硬盘（刚下了新歌可以用） |
| **关闭** | 关界面（或按 `Esc`） |

## 三、听本地音乐

### 音乐库怎么来的

**自动扫描整个硬盘**（`C:\` 和 `D:\`），找到的歌曲自动进库。

过滤规则（避免把音效素材也扫进来）：

| 规则 | 值 |
|---|---|
| 只收格式 | `.mp3` `.wav` `.flac` |
| 时长下限 | 20 秒（排除鼓点、音效片段） |
| 跳过目录 | `Windows`、`Program Files`、`AppData`、`Temp`、`node_modules` 等 |
| 上限 | 6000 首 |

**扫描在你启动游戏时自动跑一次**，约 13~30 秒（在后台线程，不卡游戏）。

### 怎么播放

1. 确认左上角是「本地播放」
2. 在左侧歌单里**点一首** → 立刻开始播
3. 或者用**搜索框**过滤：输入 `黄凯芹` → 只剩 3 首

搜索匹配**歌名、艺术家、专辑、文件名**四者之一。

> **小技巧**：你的音乐库文件名很乱（比如 `恐怖音乐.mp3`），但 mod 读的是 **ID3 标签**里的真实信息，所以列表里显示的是 `7 Weeks & 3 Days — Mbbwe1` ✓

### 新下载的歌怎么进库

**网络搜到的歌下载后会存到 `D:\音乐\_网络下载\`**，而且下载完自动触发重扫 → 立刻出现在本地列表里 ✓

所以你可以：**网络搜索听一遍 → 觉得好听 → 切到本地模式就能直接播了**。

## 四、搜 B站 上的歌

1. 点「本地播放（点击切网络搜索）」→ 变成「网络搜索」
2. 确认「提供商」是 **B站（音频区）**
3. **在搜索框输入关键词**（比如 `歌唱祖国`）
4. **点「搜索」按钮** ← 必须点这个，光输入不会搜
5. 等 3~5 秒，左侧出现结果

```
《歌唱祖国》高清视频歌曲              3:8
在百万豪装录音棚大声听 中国广播艺术…     3:8
歌唱祖国完整版（武汉军运会版）         3:39
【4K60FPS】林妙可《歌唱祖国》20…      2:30
```

6. **点某一首** → 底部会依次显示：

```
解析 BV1EKmhBiEnW …     ← 查视频信息
下载中 45%              ← 下载中（能看到百分比）
解析中…                 ← ffmpeg 转成 WAV
（开始播放）
```

**第一次点某首歌要等几秒**（下载 + 转换），之后就流畅了。

## 五、和朋友一起听

### 前提

**双方都装了 dshmusic**，并且**在同一个服务器上**。

### 设置步骤

**你这边：**

1. 右键木棍 → 点「选择共享的玩家 (0)」
2. 勾选要一起听的朋友（可以点「全选」）
3. 返回 → 点「共享音乐： 关」→ 变成「开」

**朋友那边：**

1. 也要右键木棍 →「共享音乐」打开 → 把**你**勾上（双向）

### 之后会发生什么

你换歌时，朋友会收到一条这样的私聊：

```
PlayerOne 悄悄地对你说: [DSHM]oJrQcy0WpjsFXTVnPLziGF0-Edg32gsg…
```

**这串乱码不是垃圾** —— 是加密后的曲目信息。朋友的客户端会自动解密并跟上：

| 你在放什么 | 朋友那边 |
|---|---|
| **B站 上的歌** | 朋友**自己去 B站 下载**同一首并播放（不用传文件） |
| **本地某首歌，朋友也有** | 朋友播自己的那份，进度对齐 |
| **本地某首歌，朋友没有** | 朋友**用歌名去 B站 搜一个替代版本**播放，并提示「没有该文件，改放 B站 上找到的：「…」」 |
| 本地歌且朋友没有、B站 也搜不到 | 提示「没有该文件，B站 上也搜不到「XXX」」 |

### 三条要知道的事

**① 换歌才发消息，不是每帧都发。** 所以不会刷屏。

**② 拖动进度条也会同步。** 跳超过 1.5 秒就会通知对方。

**③ 私聊指令默认 `/w`。** 如果你玩的服用的是 `/msg` 或 `/tell`，需要改（目前没有界面入口，得改代码或加启动参数）。

## 六、常见问题

### Q：拿木棍了但屏幕底下什么都没出现

**先确认手上真的是木棍**（主手或副手）。如果你拿的是别的物品，面板按设计不显示。

### Q：显示「已索引 0 首」

说明扫描没找到歌。可能性：
- 扫描还没跑完（首次启动要 15~30 秒，等等）
- 你的歌是 `.m4a` 或 `.ogg` 格式 —— **这两种不支持**（Java Sound 解不了），只支持 mp3 / wav / flac
- 歌短于 20 秒（被当成音效过滤了）

### Q：点了 B站 的结果但不出声

**检查 ffmpeg 存不存在。** 网络音频需要本地有 ffmpeg 来转换格式：

```
会自动在这些位置找：
  D:\hiyori\resources\tools\ffmpeg.exe     ← 你的机器上有这个
  D:\ZW3D\ffmpeg.exe
  PATH 环境变量里的 ffmpeg
```

找不到会在 HUD 上提示「找不到 ffmpeg，无法解析音频」。

### Q：音乐一顿一顿的

**已经修过了**。历史原因记录：之前用的是 Java 内置的 AAC 解码器，它遇到解不了的帧**不报错、直接输出静音**（实测 80.2% 的包是静音）。现在改成**下载后用 ffmpeg 转 WAV 再播**（实测 0% 静音）。

如果还卡，告诉我具体现象（游戏卡 还是 声音断续）。

### Q：共享发了但对方没反应

按顺序排查：
1. **对方装了吗？** 没装的话那串密文他看不懂，什么都不会发生
2. **对方的「共享音乐」开了吗？** 需要双向
3. **对方把你勾上了吗？**
4. **服务器允许 `/w` 吗？** 有些服禁私聊
5. **看对方的聊天框**有没有 `§b[音乐]` 开头的提示

### Q：命令太长了发不出去

不会。加密后的命令最长 238 字符（含玩家名），聊天上限是 256 ✓。带歌名的载荷已经实测过边界。

### Q：歌名里有引号怎么办

会**被剥掉**（`XXX"---` → `XXX---`）。已实测 12 个恶意/边界歌名，都不会破坏消息结构，也伪造不了曲目 ID。代价只是歌名里少个引号，不影响搜索。

### Q：为什么显示的歌名和文件名不一样

因为读的是 **ID3 标签**（文件内嵌的真实信息），不是文件名。你的库里文件名很随意，标签才是准的。

## 八、给进阶用户

### 启动参数

```
-Ddshmusic.root=D:\音乐          扫描时优先包含这个目录
-Ddshmusic.roots=C:\;D:\         完全覆盖扫描范围（分号分隔）
-Ddshmusic.downloads=D:\音乐\_网络下载   下载存放位置
-Ddshmusic.ffmpeg=C:\path\ffmpeg.exe    指定 ffmpeg 位置
```

### 共享消息的格式

```
[DSHM]<base64url>
        └─ AES-256-GCM，随机 nonce
           nonce(12) + 密文 + 认证标签(16)
```

解密后的内容：

```json
{"v":1,"i":"net:BV1TVZXBqEaC","s":470,"t":1699000000}
```

| 字段 | 含义 |
|---|---|
| `v` | 格式版本 |
| `i` | 曲目身份。`net:` 前缀 = B站 曲目（后面是 bvid）；16 位十六进制 = 本地文件指纹 |
| `n` | 歌名（**仅本地文件载荷带**，用于对方找替代版本，截断 20 字符） |
| `d` | 时长秒数（**仅本地文件载荷带**，用于挑时长最接近的替代） |
| `s` | 播放位置 × 10（470 = 47.0 秒） |
| `t` | 发送时间戳（对方用它补偿消息延迟） |

**注意**：密钥**硬编码在 mod 里**，所以这是**混淆**不是安全加密 —— 拿到 jar 的人就能解密。真正有意义的是 GCM 认证标签：被篡改的消息会解密失败被丢弃。
